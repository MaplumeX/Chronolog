# 重新设计统计界面为四种统计视图

## Goal

将统计页（`web/src/pages/StatsPage.tsx`）从「同一套图表换查询窗口」的快速切换器，重设计为 4 种各有侧重的统计视图。每个视图回答一个不同的问题：

- **日视图**：「这 24 小时是怎么构成的」——当日结构
- **周视图**：「一周的节奏与结构如何」——每日堆叠形态 + 分类环比
- **月视图**：「习惯的形态」——按分类着色的热力图 + 记录纪律
- **自定义视图**：「自由分析」——任意区间

## 产品前提（用户明确）

本项目是柳比歇夫时间管理软件，**默认假设用户把一天 24 小时全部记录下来**。由此推出：

- 每日总时长 ≈ 24h 是近似常数——总量、总时长环比、日均总时长、活跃天数等「量」指标无信息量，**不做**
- 统计主角是**结构**：各分类占比及其变化、时段分布
- 「未记录」时段是记录缺失，作为显式灰桶参与占比与覆盖度统计（是自律指标，不是要隐藏的空闲）
- 统计图表分母天然是 24h/168h/当月小时数

## Background（现状证据）

- `StatsPage.tsx`：四个档位（today/week/month/custom）只是计算不同的 `from/to` 传给 `api.statsRange`，渲染完全相同的图表组（总时长卡 + 逐日柱状图 + 分类饼图/条形列表 + 标签条形列表）。日档的「逐日趋势图」只有 1 根柱子，月档的总量柱永远等高，均无信息量。
- 后端 `/api/stats/range`（`server/src/routes/today.ts:65` → `server/src/entries.ts:431 statsRange`）返回 `RangeStats`：`totalSeconds`、`categories[]`、`tags[]`、`days[]`（逐日秒数，含 0 天）、`entries[]`（区间内条目，含 startedAt/stoppedAt）。区间上限 92 天。
- 今日档有 5s 轮询（跨午夜滚动 + 数据实时更新），其余档位不轮询。
- 现有横切能力：tag 筛选（tagId 参数）、分类汇总/独立切换（rollup 参数）。
- 可复用资产：DateNav（`web/src/components/DateNav.tsx`，日期导航交互范式）；recharts（Bar/BarChart/Pie/PieChart 等）；现有 Calendar（自定义区间选择）。
- i18n 文案在 `web/src/i18n/locales/zh.ts` / `en.ts`。

## Requirements

### R1 日视图
- **24h 环形图**（主图）：0 点在顶、顺时针一整圈代表一天；各分类按时段顺序分段着色，未记录时段为灰色弧段；中心显示覆盖度（如 `23h10m / 24h`）。
- **分类构成列表**：各分类弧段时长 + 占 24h 百分比；未记录灰桶同列。
- **时段分布堆叠柱**：24 桶（每小时），桶内按分类颜色堆叠；显示一天的结构节奏。
- 日期导航（上一天/下一天/回今天）。
- 「今天」保留 5s 轮询实时更新；历史日期不轮询。
- 不嵌入 24h 时间线（用户已决策）。

### R2 周视图
- **每日结构堆叠柱**：7 根柱（周一..周日），每根为当天分类堆叠（归一化展示一天构成；未记录为灰段）；信息在分层形态而非柱高。
- **分类环比**：逐分类列出本周 vs 上周时长与 ▲/▼ 百分比（上周为 0 显示 "—"）；不显示总时长环比（总量近似恒定 168h）。
- 周导航（上一周/下一周/回本周）。

### R3 月视图
- **按分类着色的日历热力图**：顶部分类下拉选择器（默认 = 当月占比最大的分类）；每格颜色深浅 = 该分类当天时长；未记录整天为特殊样式；hover 显示 `M月d日 · 时长`；本月未来日期禁用。
- **KPI 行**：
  - 记录完整度：完全记录天数 / 当月已过天数（或近似：有记录天数/已过天数，文案明确）
  - 连续记录天数（当月窗口内最长连续有记录天数）
  - 所选分类的月合计、日均值
- **环比上月**：所选分类的月合计 delta（▲/▼）。
- 月导航（上月/下月/回本月）。

### R4 自定义视图
- 日期区间选择（保留现有 range Calendar）。
- 逐日分类堆叠趋势图（各天分类构成随时间的形态变化）+ 分类/标签分布列表。
- 现有校验保留（from≤to、≤92 天、完整选择）。

### R5 横切
- tag 筛选、分类 rollup 切换在所有视图保留生效（tag 筛选下「未记录」桶 = 当日未被该 tag 覆盖的时间）。
- 视图切换控件从「快速档位 Tabs」改为「视图 Tabs」（日/周/月/自定义语义）。
- i18n：中英文文案（zh/en translation keys）。

## Out of Scope

- 工作日 vs 周末对比（用户明确不做）
- 总时长 / 总量环比 / 活跃天数 / 日均总时长等「量」指标（完整记录前提下无信息量）
- 24h 时间线嵌入日视图（用户已否决）
- 双区间对比（A vs B）、CSV 导出、goals 目标进度接入
- 后端新 API（覆盖度/未记录桶/堆叠聚合均由前端基于 `entries[]` 计算；环比 = 前端二次请求 `statsRange`）
