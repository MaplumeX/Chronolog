# 计时页支持当天/本周视图切换

## Goal

计时页时间线支持在"当天"与"本周"两个视图间切换：

- 当天视图：现有 24h 纵向时间线（单日）
- 本周视图：周一至周日 7 天并排，每天一列 24h 刻度

## Requirements

- 时间线头部提供分段切换控件（当天 / 本周），默认当天
- 本周边界为 ISO 周：周一 00:00 至周日 24:00，按浏览器时区计算
- 本周视图：7 列并排，每列显示该天 0:00–24:00 刻度与记录块；列头显示星期与当天总时长
- 本周视图头部显示周范围（如"8月25日 – 8月31日"）与本周总时长
- 跨天记录在覆盖的每一天各显示一段（与当天视图的 clip 语义一致）
- 运行中的记录在当天列实时增长；now-line 显示在当前所在天
- 切换视图时按需加载数据；计时开始/停止后刷新当前视图数据
- 所有新增文案走 i18n（zh/en）

## Acceptance Criteria

- [ ] 计时页头部出现"当天 / 本周"切换控件，默认当天
- [ ] 当天视图行为与现状一致（回归）
- [ ] 本周视图显示周一至周日 7 列，每列 24h 刻度与记录块
- [ ] 本周边界为 ISO 周（周一 00:00 起），按浏览器时区计算
- [ ] 跨天记录在两天各显示一段，时长按天裁剪
- [ ] 运行中记录在当天列实时增长；now-line 显示在当前天
- [ ] 头部显示周范围与本周总时长；列头显示星期与当天总时长
- [ ] 后端 `GET /api/entries/week?tz=` 返回 7 天数据；无效 tz 返回 400
- [ ] 后端测试覆盖周边界、跨天裁剪、运行中条目
- [ ] `npm test -w server`、`npm run typecheck`、`npm run build` 通过
- [ ] 新增文案均有 zh/en 翻译

## Notes

- 用户确认：本周 = 周一至周日（ISO 周）；7 天并排纵向时间线（每天一列，24h 刻度）
- 切换控件采用分段控件（shadcn Tabs），位于时间线头部
- 视图状态为页面级 state，不持久化
