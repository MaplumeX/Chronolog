# PRD: 优化周视图样式

## 背景

周视图（`Timeline.tsx` 的 week 模式）当前存在以下体验问题：

1. 列头只显示星期文案（如"星期二"），没有日期数字，用户难以快速定位具体日期。
2. 当天没有视觉标注，只有时间线内的红色 now-line，列头层面无法一眼看出今天。
3. 空的天显示"无记录"提示，视觉噪音大。
4. 每列都渲染自己的时间刻度（06:00 / 07:00 / 08:00 …），横向网格线不连续，视觉割裂。

## 需求

1. **列头显示日期**：列头显示"8 星期二"（日期数字 + 星期），数字要大、粗一点，星期文案相对次要。
2. **当天标注**：当天列头要有明显的视觉标注（如高亮背景/边框/圆点），区别于其他天。
3. **去掉空提示**：没有记录的天不显示"无记录"（`timeline.weekEmpty` 不再使用）。
4. **网格穿透七天**：时间刻度只在最左侧显示一次，横向网格线贯穿全部七天，每列不再重复显示 06:00/07:00/08:00。

## 约束

- 仅改动前端（`web/src`），后端接口不变。
- day 模式（单日视图）的现有行为不应被破坏；若结构重构影响 day 模式，需保持其视觉与功能一致。
- 保持现有 i18n 结构；`timeline.weekEmpty` 文案可保留在 locale 文件中但不再被引用（或按需移除引用）。
- 遵循现有代码风格（Tailwind + styles.css 混合、`format.ts` 工具函数模式）。

## 验收标准

- [ ] 周视图每列列头显示"日期数字 + 星期"，数字大且粗。
- [ ] 当天列头有区别于其他天的视觉标注。
- [ ] 空的天不显示任何"无记录"提示。
- [ ] 时间刻度只在最左侧出现一次，横向网格线贯穿七天。
- [ ] day 模式视觉与功能不变。
- [ ] `npm run build`（web）通过，无 TypeScript 错误。
