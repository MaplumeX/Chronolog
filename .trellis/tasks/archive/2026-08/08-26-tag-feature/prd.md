# 标签功能：多标签支持（计时器输入/时间线展示/统计筛选/标签管理）

## Goal

为时间记录应用添加多标签（多对多）功能：每条时间记录可打多个标签；计时器开始时可选择标签；时间线展示标签；统计页可按标签筛选；提供标签管理页（创建/重命名/删除）。

## Requirements

### 数据模型

- 标签独立于分类存在，与时间记录为**多对多**关系（一条记录可打多个标签，一个标签可被多条记录使用）。
- 标签按用户隔离（user-scoped），同名标签在同一用户下唯一。
- 标签删除时，其与时间记录的关联一并清理（关联表 ON DELETE CASCADE）。删除策略：**直接删除并解除关联**（与分类的"占用即拒绝"不同），管理页删除时弹确认框。

### 计时器输入

- 开始计时时，除选择分类、填写说明外，可通过**多选下拉**为一个或多个标签打勾（从已有标签中勾选，新标签需先到标签管理页创建）。
- 正在运行的计时记录展示其已选标签。

### 时间线展示

- 当日时间线（Timeline）的每条记录展示其标签（如小徽章/小圆点形式）。
- 标签展示不破坏现有时间线布局（full/compact/mini 三档）。

### 统计筛选

- 统计页（StatsPage）可按标签筛选：选中某个标签后，仅统计带该标签的记录。
- 筛选为可选交互，默认展示全部。

### 标签管理页

- 新增"标签"导航入口与页面，支持创建、重命名、删除标签（删除需用户确认）。

### 国际化

- 新增文案同时提供中文（zh）与英文（en）。

## Acceptance Criteria

- [ ] 数据库新增标签表与记录-标签关联表；`SCHEMA_SQL` 与 `schema.ts` 同步更新；已有数据库可平滑升级（CREATE TABLE IF NOT EXISTS，无破坏性变更）。
- [ ] 后端提供标签 CRUD API（列表含使用次数、创建、重命名、删除），删除时级联清理关联。
- [ ] 计时开始 API 接受 `tagIds` 数组并写入关联；`EntryDto` 返回 `tags` 数组；`/api/timer/current`、`/api/entries/today` 均返回标签。
- [ ] 统计 API 支持可选 `tagId` 查询参数，仅统计带该标签的记录。
- [ ] 前端计时器开始时可多选标签；运行中展示已选标签。
- [ ] 时间线每条记录展示标签徽章。
- [ ] 统计页提供标签筛选下拉/选择器，筛选后按标签过滤统计。
- [ ] 新增"标签"导航页：创建、重命名、删除（删除需确认，删除后关联解除）。
- [ ] 中英文文案齐全。
- [ ] 后端测试覆盖：标签 CRUD、删除级联、计时带标签、统计按标签筛选、用户隔离。
- [ ] `npm run typecheck` 与 `npm test` 通过。
