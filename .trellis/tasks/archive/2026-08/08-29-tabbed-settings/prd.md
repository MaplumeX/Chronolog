# PRD: 将侧边栏多余项移入分 Tab 设置页

## 背景

当前侧边栏主导航含 API Tokens（低频管理功能），footer 堆积了语言切换器、登出按钮、主题切换器。这些功能让侧边栏变得杂乱，且登出/语言/主题本质上是"设置"类操作。

## 需求

1. **侧边栏瘦身**
   - 主导航只保留：计时、统计、分类、标签。
   - footer 只保留用户按钮（点击进入设置页）。
   - 移除 footer 中的：语言切换器、登出按钮、主题切换器。

2. **设置页改为 Tab 结构**，共三个 tab：
   - **通用**：语言切换、主题切换（外观）。
   - **账户**：个人资料、修改密码、退出登录、危险操作（注销账户）。
   - **API Tokens**：现有 TokensPage 的完整功能（创建/复制/撤销 token）。

3. **API Tokens 页面从主导航移除**，仅作为设置页的一个 tab 可达。

## 约束

- TokensPage 现有功能不缩减：创建、复制显示一次、撤销、错误提示均保留。
- 主题/语言切换的现有行为（持久化、即时生效）不变，只换位置和呈现形式。
- 移动端侧边栏（抽屉模式）同样只显示瘦身后的导航。
- 移动端设置页 tab 布局需可用（tabs 组件响应式或允许横向滚动）。

## 验收标准

1. 侧边栏（含折叠 icon 模式与移动端抽屉）不再出现语言、主题、登出、Tokens 入口。
2. 设置页显示三个 tab：通用 / 账户 / API Tokens，切换正常。
3. 通用 tab 中语言切换与主题切换即时生效且刷新后保持。
4. 账户 tab 中资料保存、密码修改、退出登录、注销账户功能正常。
5. API Tokens tab 功能与迁移前一致。
6. 原独立 tokens 路由/页面入口（PageId "tokens"）被移除，无死代码残留。
7. 中英文 i18n 文案齐全，无缺失 key。
8. `npm run build`（web）通过，无类型错误。
