# Toggl-style date switcher for timer timeline

## Goal

在 Timer 页时间线上方提供 Toggl 风格的日期切换器，让用户可以查看过去任意日期/周的时间条目，而不是只能看"今天/本周"。

## Background（Toggl 参考）

Toggl Track Timer 页的 Date Picker 交互：

- `[←] <日期范围文字> [→] ✕`，位于时间条目区上方
- 左右箭头按当前视图粒度移动（day 视图移动一天，week 视图移动一周）
- 点击日期文字弹出日历选择具体日期
- ✕ / "Today" 一键回到今天，仅在偏离今天时显示
- （Chronolog 调整：允许切到未来日期；回今天的按钮用文字"今天"而非 ✕）

## Requirements

- R1: Timer 页 Timeline 上方增加日期导航条：`← [日期标签] →`，右侧为 day/week 视图切换（保持现有按钮）
- R2: 左箭头向前移动（day 视图 -1 天，week 视图 -1 周）；右箭头向后移动，允许切到未来日期（不禁用）
- R3: 点击日期标签弹出日历（Popover + Calendar），可选择任意日期（含未来）
- R4: 日期标签显示规则：今天/本周显示动态标签（"今天"/"本周"），偏离后显示静态日期（day: 如 "6月15日" 或 ISO 日期；week: 如 "6月9日 – 6月15日"）
- R5: 处于今天/本周时隐藏"今天"按钮（文字按钮，位于右箭头旁），偏离后显示，点击回到今天/本周
- R6: day/week 视图共用同一日期状态；切换视图时保持所查看的日期落在对应范围内（例如查看周三时切到 week 视图，应定位到周三所在周）
- R7: 选中的日期持久化到 localStorage，刷新页面后保留；回到今天时清除
- R8: 后端 `/api/entries/today` 与 `/api/entries/week` 增加可选 `date` 参数（`YYYY-MM-DD`，按 tz 解释），不传时行为不变（默认今天）
- R9: 不做合计时长显示（明确排除）
- R10: StatsPage 不跟随日期选择器，保持只看今天
- R11: 顶部计时条不受日期切换影响，正在计时的条目照常显示和走秒

## Acceptance Criteria

- [ ] AC1: 在 day 视图点 ← 可看到昨天的条目，标签变为昨天日期，且出现"今天"按钮
- [ ] AC2: week 视图点 ← 切到上一周，标签显示该周范围
- [ ] AC3: 在查看某天（如周三）时切到 week 视图，显示的是该天所在周
- [ ] AC4: 右箭头可切到明天/下周，日历中未来日期可选；查看今天/本周时不显示"今天"按钮
- [ ] AC5: 点击日期标签可打开日历并选择日期，Timeline 随之刷新
- [ ] AC6: 选择非今天后刷新页面，日期选择保留；点击"回到今天"恢复默认
- [ ] AC7: 不传 `date` 参数时后端接口行为与现状完全一致
- [ ] AC8: 计时条在查看过去日期时仍正常显示并走秒
- [ ] AC9: `npm run typecheck`（server + web）与现有测试通过；新增后端 date 参数校验有测试覆盖
- [ ] AC10: 界面文案（今天/本周/回到今天）走 i18n（zh/en）

## Constraints

- 前端使用现有 shadcn/ui 组件（Popover/Calendar/Button），风格与现有一致
- 时区处理沿用现有 browserTz + 后端 tz 参数模式
- 后端 date 参数无效时返回 400 VALIDATION 错误（与现有错误风格一致）
