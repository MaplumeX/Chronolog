# PRD: 修复设置页 tab 滚动条并将侧边栏设置入口拆为独立按钮

## 需求

1. **移除设置页 TabsList 的 `overflow-x-auto`**
   - 上个任务加的"小屏安全余量"，在桌面端渲染出常驻横向滚动条；实测三个 tab 不会溢出，直接删除。

2. **侧边栏设置入口重构（方案 B）**
   - footer 用户名按钮改为纯展示（不可点击、无 tooltip 跳转语义）。
   - 新增独立"设置"按钮：齿轮图标（`Settings` from lucide）+ "设置"文字，点击进入设置页，风格与主导航项一致。
   - 折叠 icon 模式下：用户名缩为首字母头像，设置按钮降级为纯齿轮图标。
   - 移动端抽屉：点击设置后关闭抽屉。

## 约束

- 用户名纯展示区在折叠 icon 模式下仍显示首字母（保持现有视觉）。
- 不改动主导航、设置页内部结构。

## 验收标准

1. 设置页 TabsList 无横向滚动条（桌面与窄屏均无）。
2. 侧边栏 footer：用户名为纯展示不可点击；下方/旁边有独立"设置"按钮，点击进入设置页。
3. 折叠 icon 模式与移动端抽屉表现正常（点击设置进入并关闭抽屉）。
4. `cd web && npm run build` 通过。
5. i18n 复用现有 `nav.settings` key，无新增缺失。
