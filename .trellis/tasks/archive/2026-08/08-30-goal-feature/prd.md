# 目标（Goal）功能

## Goal

用户可以创建"目标"来约束或追踪自己的时间投入：目标有名称和 emoji 图标，可关联
一个分类和/或一个标签，可配置可选的截止日期；达成条件为"在所选周期单位
（天/周/月）内，匹配的时间条目总时长 少于 / 大于 X 小时"。

## Background（代码库事实）

- 后端：Fastify 路由（`server/src/routes/`），Drizzle + better-sqlite3；schema 在
  `server/src/schema.ts`，建表 SQL 与幂等迁移在 `server/src/db.ts`。
- `time_entries` 必属一个 category，可选多 tag（entry_tags 多对多）；categories/tags
  均为 user 私有。category 有关联条目时禁止删除（409）。
- `server/src/time.ts`（luxon）：已有 tz 校验、day/ISO-week 窗口、`clipSeconds`
  跨窗口截断、运行中条目按 now 裁剪等逻辑，可直接复用；月窗口可用
  `rangeDayBounds` 以月初~月末表达。
- 前端：React SPA，PageId state 路由（`Shell.tsx`），shadcn 风格 ui 组件，
  i18n（zh/en），StatsPage 已有 tz 处理与日期格式化模式可参考。
- 分类/标签校验模式：zod `parseBody` + `AppError`；越权/不存在返回 404。

## Requirements

- R1 基本属性：名称（必填）、emoji 图标（内置网格选择，默认 🎯）。
- R2 关联（最多 1 分类 + 1 标签）：只设分类 → 统计该分类全部条目；只设标签 →
  统计带该标签的全部条目；都设 → 仅统计"属于该分类且带该标签"（AND）；
  都不设 → 统计全部条目。
- R3 截止日期：可选，默认不填 = 永久有效；到期后目标标记"已过期"，列表中
  置灰排到末尾，保留数据、可手动删除，不自动隐藏。
- R4 达成条件：比较方向（少于 / 大于）+ 目标小时数 X + 周期单位（天 / 周 / 月）。
- R5 进度：按当前周期窗口（天=本地日，周=ISO 周一起，月=自然月）实时统计匹配
  条目总时长（运行中条目按当前时间截断），与 X 比较，得出达成状态与进度。
- R6 CRUD：后端 REST API（list 带进度、create、patch、delete）+ 前端目标
  管理页（列表、新建/编辑表单、删除确认）。
- R7 引用完整性：目标关联的分类/标签被删除时阻止删除（409，与分类-条目
  的现有保护一致）；关联的分类/标签重命名不影响目标。

## Acceptance Criteria

- [ ] AC1 创建目标：填名称、选 emoji、可选分类/标签、方向（少于/大于）、小时数、
      周期（天/周/月）、可选截止日期；创建成功后出现在列表中。
- [ ] AC2 进度正确性：目标关联分类「学习」时，当天「学习」条目总时长（含运行中
      条目按 now 截断、跨午夜条目按窗口截断）正确计入当天窗口；周/月窗口同理。
- [ ] AC3 AND 语义：同时设置分类+标签的目标只统计"该分类且带该标签"的条目。
- [ ] AC4 达成判定："大于"目标在当前窗口累计 ≥ X 小时时显示达成；"少于"目标在
      当前窗口累计 < X 小时时显示达成，超出时显示超限状态。
- [ ] AC5 过期目标：截止日期早于 tz 本地今天的目标显示"已过期"、置灰、排在
      列表末尾，不再统计进度。
- [ ] AC6 编辑/删除：可修改目标的任意字段；删除需确认；被目标引用的分类/标签
      删除时返回 409 并提示。
- [ ] AC7 校验：空名称、非正数小时数、无效截止日期、不存在的分类/标签 id 均
      返回 400/404；越权访问他人目标返回 404。
- [ ] AC8 i18n：目标页面中英文文案完整（zh/en locale 同步新增 key）。
- [ ] AC9 测试：后端 goals 路由（CRUD、进度、窗口边界、AND 语义、过期、
      引用保护）有测试覆盖，`npm test` 通过；`npm run typecheck` 通过。

## Out of Scope

- 历史周期达成记录/连续打卡统计（streak）、通知提醒、目标排序拖拽、
  API Token 化的 goals 接口文档、多分类/多标签关联。
