# 轴视图：日视图内的条目列表显示方式

## Goal

在现有「日」视图内部提供两种显示方式切换：**块视图**（现有比例尺时间块）
与**条目视图**（轴视图）。轴视图为：左侧时间列（开始/结束两行式）+ 刻度短线，
右侧按时间顺序排列的可变高度条目卡片。
参考「时间日志」(solitude) 的轴视图、aTimeLogger 的 History 列表——
非比例流水列表，短条目与长条目同等可读，适合回顾/翻阅一天的记录。

轴视图是 **day 模式的子视图**，不是与日/周并列的第三模式：
- 顶层 Tabs 仍为 日 / 周 两档，数据流、DateNav、boundary 逻辑均不变。
- 仅 day 模式下显示「块/条目」切换控件；week 模式无此切换。
- week 模式下点某天查看条目（列头跳转）首版不做（Out of Scope）。

## Background

- 现有 `web/src/components/Timeline.tsx` 的 day 视图是**比例尺视图**（块高∝时长），
  1 分钟的条目被压缩成 mini 块，难以阅读。
- 轴视图是**非比例**列表：每个条目占一行，天然适合短条目密集的场景。
- 数据零新增：完全复用 `TodayEntries`、`categories`、`tags`、gap 计算（`computeGaps`）。
- 设计演变：轴线+节点卡片 → 紧凑表 → 「紧凑表 + 可变高度卡片」混合形态；
  架构演变：独立第三模式 → day 子视图（用户决策，更贴合心智模型）。

## Requirements

### R1 显示方式入口（day 子视图）

- day 模式下提供「块 / 条目」切换控件（图标按钮对，位于现有缩放按钮旁或
  Tabs 右侧；week 模式下隐藏）。
- 切换仅影响渲染：数据（today/gaps）、DateNav、合计、选中编辑全部共享。
- 子视图选择记忆在 localStorage（`chronolog-day-subview`，`block` | `entries`），
  失效回退 `block`。
- 切到条目视图时块视图的缩放档位（scale）状态保留，切回时恢复。

### R2 左侧时间列（两行式）

- 每个条目在时间列显示**两行**：上行 = 开始时间（`HH:MM`），下行 = 结束时间（`HH:MM`）。
- 上行用 `foreground` 亮度、下行用 `muted-foreground`（开始是锚点，结束是补充）。
- 两行均 `tabular-nums` 右对齐、`leading-tight`；时间列固定宽度（≈56px，窄屏可微调）。
- 时间列与卡片之间有**刻度短线**（横向 1px 淡色短线 + 节点感），保留一点「轴」的串联感。
- 运行中条目：下行显示 `···`（muted 色，含义「尚未结束」），不显示每秒跳动的数字。
- 跨午夜条目：结束时间显示原样 HH:MM（跨天语义由日期导航上下文承担）。

### R3 右侧条目卡片（可变高度）

- 无描述且无标签 → **单行卡**（≈44px 触控友好高度）：描述位显示分类名 +
  分类色点，右对齐时长。
- 有描述或标签 → **两行卡**：上行描述（`font-medium`），下行分类色点 + 分类名 +
  标签徽章 + 右对齐时长。
- 卡片**不含时间范围**（时间归左列、内容归右卡）。
- 卡片样式：
  - 底色 = 分类色极淡染色（`color-mix(in srgb, 分类色 ~6-8%, background)`），
    hover 提亮（~15%）。
  - 左缘 3px 分类色竖条（与现有 timeline-block 色条语言同源，色弱友好双编码）。
  - 圆角沿用现有 Card 组件语言（`rounded-lg`），卡片间 `gap-2`。
  - 选中（编辑中）：`ring-primary/50`；popover 定位锚定卡片（复用 PopoverAnchor 手法）。
- 运行中条目卡片：左缘色条呼吸动画 + 时长随 nowMs 每秒递增 + `◉` 图标。
- 颜色逻辑复用 `paletteColor` / `paletteForegroundColor`（分类显式色优先，hash 回退）。
- 点击卡片 → 复用现有 `EntryEditor` popover 流程（同 timeline-block 的选中编辑）。

### R4 空档幽灵卡（gap）

- 条目之间的空档渲染为**虚线边框幽灵卡**（高度约为正常卡一半，内容居中
  `+ 空档 xx 分钟`），时间列同步显示空档起止两行。
- 点击幽灵卡 → 以空档起止创建草稿，复用现有 gap draft popover 流程
  （`gapDraft` + EntryEditor draft）。
- 空档跨午夜/跨边界时按可见窗口截断（复用 `computeGaps` 输出，与现有 slot 语义一致）。

### R5 排序

- 默认按开始时间**正序**（流水账式，柳比歇夫记账习惯：从早到晚阅读）。
- 提供顺序切换（正序/倒序），记忆在 localStorage（`chronolog-entry-view-sort`）。

### R6 移动端适配

- 移动端同样可用（触摸点击卡片编辑、点击幽灵卡补录）。
- 时间列固定宽度，卡片占余下宽度；卡片内容窄屏换行（flex-wrap）。

### R7 列表收尾（结账线）

- 列表底部收一根细线 + 居中淡色「日期 · 合计时长」（账本结账线语义），
  首尾呼应；今日视图运行中条目在最底部时结账线仍显示当日已积累合计。

## Out of Scope

- week 模式下的条目显示（列头点击某天跳转 day+条目视图）——后置。
- 不做条目的拖拽创建/拖拽移动（保留块视图的拖拽创建，条目视图纯展示+点击编辑）。
- 不做按小时/上午-下午分组（首版不做，观察需求）。
- 不做行内迷你 24h 分布条、左右交错布局、半比例行高（评估后放弃的备选方案）。
- 不改后端 API（完全复用现有接口与数据结构）。

## Acceptance Criteria

- [ ] AC1 day 模式下出现「块/条目」切换：条目视图正常渲染，DateNav/合计正常；
      week 模式下无此切换控件。
- [ ] AC2 切换记忆保持（localStorage），刷新后停留在上次子视图；块视图缩放档位
      在来回切换后保留。
- [ ] AC3 时间列两行式：上行开始时间（亮）、下行结束时间（淡）、`tabular-nums`
      右对齐；运行中条目下行显示 `···`。
- [ ] AC4 可变高度卡片：无描述无标签为单行卡，否则两行卡；卡片不含时间范围，
      含描述/分类色点/分类名/标签/右对齐时长。
- [ ] AC5 卡片底色为分类色极淡染色 + 左缘 3px 色条；选中态 ring。
- [ ] AC6 运行中条目卡片时长每秒递增，左缘色条有呼吸动画。
- [ ] AC7 点击卡片打开 EntryEditor（popover），编辑保存后列表刷新。
- [ ] AC8 空档显示虚线幽灵卡（含起止时间两行），点击后以空档起止打开创建草稿。
- [ ] AC9 无缝衔接的相邻条目（上条结束 = 下条开始）时间列数字呼应，视觉连续。
- [ ] AC10 列表底部有结账线（日期 + 合计时长）。
- [ ] AC11 可切换正序/倒序，刷新后记忆保持（localStorage）。
- [ ] AC12 无条目的一天显示空状态（非报错）。
- [ ] AC13 移动端布局可用、触控目标 ≥44px。
- [ ] AC14 typecheck + 既有测试全绿，新增组件有对应测试。
