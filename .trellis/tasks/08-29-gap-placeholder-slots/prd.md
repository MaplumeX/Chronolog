# Timeline gap placeholder slots for quick entry creation

## Goal

在时间线的两个已有条目之间的空档（gap）渲染一个静态可见的占位插槽（placeholder slot），用户点击插槽即可原地创建一条覆盖整个空档的新条目，免去拖拽或手动排序。

## Requirements

### 插槽渲染规则

- R1「两个已有条目」是相对**全部数据**而言的，不是当前视图可见的条目。
- R2 插槽样式：**虚线边框 + 灰色（半透明）内部**，静态可见，不依赖 hover 才出现。
- R3 插槽渲染范围：
  - 日视图：当天窗口内相邻两条目之间；以及当天第一条之前 / 最后一条之后的剩余空档——**仅当前一天有最后一条 / 后一天有第一条条目时**（跨天 gap 在日视图列顶部/底部的投影）。
  - 周视图：各列内部相邻条目之间；跨天 gap 两边各显示一个插槽（前一日列尾部一个 + 后一日列头部一个）。
- R4 点击任一侧插槽（跨天 gap 的两边），创建的条目**覆盖整个空档**（可跨午夜，如 Wed 22:00 – Thu 08:00）。
- R5 空档像素高度低于最小阈值时**不显示**插槽（阈值在实现阶段校准）。
- R6 点击插槽 → 打开 EntryEditor（复用现有 draft popover 流程），时间预填为整个空档的起止时间；保存后条目落在该位置。

### 数据需求

- R7 日视图渲染列顶部/底部插槽需要知道**前一天的最后一条**与**后一天的第一条**条目；周视图同理需要周首前一天的最后一条与周尾后一天的第一条。数据获取方式（后端轻量接口或前端顺带拉相邻日数据）在设计阶段决定。

## 非目标（Non-goals）

- 不改动现有拖拽创建流程。
- 不改动条目编辑/删除流程。
- 不在空档 hover 时改变插槽形态（插槽静态可见）。

## Acceptance Criteria

- [ ] AC1 相邻两条目之间（视图内）渲染虚线边框+灰色内部的占位插槽，静态可见。
- [ ] AC2 点击日视图/周视图中的插槽，EntryEditor 以整个空档的起止时间预填打开。
- [ ] AC3 跨天 gap 在周视图两列各显示一个插槽，点击任一个创建的条目覆盖整个跨天空档。
- [ ] AC4 日视图列顶部/底部在前后日有边界条目时显示插槽，点击创建的条目与相邻日条目无重叠。
- [ ] AC5 空档像素高度低于阈值时无插槽渲染。
- [ ] AC6 保存新条目后时间线正确刷新，新条目出现，原 gap 插槽消失（被新条目取代或剩余 gap 重新计算）。
- [ ] AC7 现有拖拽创建、点击编辑、选中 popover 等交互不受影响。

## Notes

- 用户已确认：不显示 hover 才出现的形态；太矮不显示；「两个已有条目」按全局数据判定；点击取整个空档。
