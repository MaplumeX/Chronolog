# Directory Structure

```
web/
├── index.html
├── components.json        # shadcn: new-york / neutral / cssVariables
├── vite.config.ts         # /api → http://127.0.0.1:8080; @ → src; Tailwind plugin
├── src/
│   ├── main.tsx
│   ├── App.tsx            # auth gate + page switch + elapsed clock
│   ├── api.ts             # fetch wrappers + DTO types + ApiError
│   ├── format.ts          # tz, duration, clocks, categoryColor, clipSeconds
│   ├── styles.css         # @import "tailwindcss" + shadcn tokens + timeline geometry
│   ├── lib/
│   │   └── utils.ts       # shadcn cn() only
│   ├── hooks/
│   │   └── use-mobile.ts  # generated by shadcn sidebar; do not add business hooks here
│   ├── components/
│   │   ├── ui/            # shadcn primitives (do not restyle by editing these first)
│   │   ├── Shell.tsx      # collapsible Sidebar: 计时 / 统计 / 分类
│   │   ├── TimerBar.tsx
│   │   ├── CategoryPicker.tsx
│   │   └── Timeline.tsx
│   └── pages/
│       ├── AuthPage.tsx
│       ├── TimerPage.tsx
│       ├── StatsPage.tsx
│       └── CategoriesPage.tsx
└── dist/                  # production; Fastify serves via WEB_DIST
```

## Where new code goes

| Kind | Put it |
|------|--------|
| New screen | `pages/XPage.tsx` + add a `PageId` in `Shell.tsx` + render branch in `App.tsx` |
| App chrome | `components/` (`Shell`, timer pieces). Not `components/ui/` |
| shadcn primitive | `npx shadcn@latest add <name>` into `components/ui/` |
| HTTP + payload types | `web/src/api.ts` |
| Duration / timezone / color | `web/src/format.ts` |
| Visual tokens | `web/src/styles.css` (`:root` + `@theme inline`) |
| `cn()` | `web/src/lib/utils.ts` only |

Do not add `src/store/` or `src/router/`. Do not add business hooks under `src/hooks/` (`useAuth`, `useTimer`). `use-mobile.ts` exists solely because Sidebar needs it.

Vite imports omit extensions (`from "./App"`). App code may use `@/components/ui/...`. Do not copy the server’s `.js` suffix style into `web/`.
